# LPC2148 Embedded Practicals

A collection of embedded systems practicals using the **LPC2148 ARM7 microcontroller**, covering peripheral interfacing, Embedded C programming, and circuit simulation.

## 📌 Overview

This repository contains practical implementations of fundamental embedded systems concepts using the LPC2148 microcontroller. It includes source code and simulation projects for various hardware interfacing experiments.

## 🔧 Practicals Included

| No. | Practical | Description |
|---|---|---|
| 1 | LED Interfacing | GPIO configuration and LED control |
| 2 | 7-Segment Display | Displaying numeric digits using GPIO |
| 3 | DC Motor Interfacing | Basic motor control using a suitable driver circuit |
| 4 | Keypad Interfacing | Reading key inputs using GPIO |
| 5 | 16×2 LCD Interfacing | Displaying characters and messages on an LCD |

## 🛠️ Hardware and Software

- **Microcontroller:** LPC2148 (ARM7TDMI-S)
- **Programming Language:** Embedded C
- **IDE / Compiler:** Keil µVision or a compatible LPC2148 toolchain
- **Circuit Simulation:** Proteus Design Suite, where applicable

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the required practical's folder under `Source_Code`.
3. Review the source code and configure the project for the LPC2148.
4. Open the corresponding circuit file from `Simulation`, if available.
5. Build the program using a compatible compiler.
6. Load the generated output into the simulation or target hardware and test the result.

## 🎯 Learning Objectives

- Understand LPC2148 GPIO programming.
- Learn peripheral interfacing techniques.
- Develop Embedded C programming skills.
- Understand the relationship between source code and circuit operation.
- Practice debugging and testing embedded applications.

## 📚 Applications

These practicals are useful for embedded systems learning, microcontroller programming practice, and academic laboratory work.
